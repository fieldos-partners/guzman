Drop a landscaping background video named `landscaping-hero.mp4` in this folder.

Recommended free sources (search "lawn mowing", "garden", "landscaping", "hedge trimming"):
  - https://www.pexels.com/search/videos/landscaping/
  - https://pixabay.com/videos/search/lawn/
  - https://mixkit.co/free-stock-video/garden/
  - https://coverr.co/

Specs:
  - Format: .mp4 (H.264 + AAC for broadest browser support)
  - Resolution: 1920x1080 minimum
  - Length: 8-15s seamless loop is ideal
  - Size: keep under ~6 MB for fast first paint

If no video is present, the section still renders with the Unsplash poster
image as a fallback (no broken state).
